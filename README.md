# 心屿｜情绪日记与自我关怀

面向年轻人的低门槛情绪记录与自助调节工具，支持：

- 每日心情记录、自定义情绪与图片
- 周视图、月视图和触发因素回顾
- 呼吸、正念、伸展等互动关怀练习
- 每日鼓励卡片与陪伴式对话
- 无手机号、邮箱的本地匿名账号
- 反馈入口

## 在线访问

GitHub Pages 发布后可直接在线使用。Pages 版本采用浏览器本地存储，账号和记录不会上传至服务器；清除浏览器数据会同时清除本地记录。

## 本地预览

```bash
python3 -m http.server 4173 --directory docs
```

然后访问 `http://127.0.0.1:4173`。

> 心屿不提供心理诊断或危机干预。如有自伤或伤害他人的紧急风险，请立即联系当地急救服务、心理危机热线或可信赖的人。
